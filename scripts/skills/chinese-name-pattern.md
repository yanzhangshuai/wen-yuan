# 中文名字模式

提取实体时，结合上下文判断名字属于哪一类，按对应方式处理：

| 类别 | 说明 | 处理 |
|------|------|------|
| **全名** | 姓 + 名（王冕 / 范进），复姓全名（诸葛亮 / 司马懿） | 作为实体，canonical 取全名 |
| **称谓式** | 姓/名 + 尊称或官职（范老爷 / 周学道），字/号（周进字推官） | 同一实体的别称，作 alias |
| **关系复合词** | X之父 / X之妻 / X之兄——描述关系，不指代具体某人 | 不建实体 |
| **描述性短语** | X老者 / 那少年 / 某公——泛指或不确定指代 | 不建实体，除非上下文明确指代某人 |

要点：

- 有名有姓 → canonical 取全名；仅称谓/官职代称 → 作为该实体的 alias，不建新实体
- 判断基于上下文，不机械套规则
