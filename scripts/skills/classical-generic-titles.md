# 古典文学泛称

泛称/称谓的语义分类与处理方式：

| 类别 | 例子 | 处理 |
|------|------|------|
| **尊称** | 老爷 / 先生 / 夫人 / 太太 / 相公 / 公子 / 小姐 / 娘子 | 本书内特指某人时，作为该实体的 alias |
| **官职** | 大人 / 学道 / 知县 / 尚书 / 皇上 / 太后 | 以官职代称，同 alias；不独立建实体 |
| **亲属** | 母亲 / 父亲 / 兄长 / 岳父 / 兄弟 | 亲属称谓，指向关系对象，不独立建实体 |

要点：

- 泛称不特指某人 → 不提取为实体
- 本书内明确特指某人（如"范老爷" = 范进）→ 作为该实体的 alias，不建新实体
