# goldset 标注规范

goldset 是文渊分析系统的质量锚（D6 · 先建裁判）。本文档定义标注口径，所有章节文件必须通过 `schema.ts` 校验，并在关键判定上与本规范一致。

## 1. 标注对象

每章一个 JSON 文件，含三个集合：`entities` / `relations` / `bioFacts`。另有 `book` + `chapterNo` 定位。

## 2. 实体（entities）

### 2.1 canonical 选取（唯一标准名）

| 情形 | 规则 | 例 |
|---|---|---|
| 有名有姓 | 取全名 | 王冕 |
| 只知姓 | 姓 + 最常用称谓 | 秦老（非"秦"） |
| 有官职且名字明确 | 取名字，官职作别名 | canonical=时仁，别名含"时知县" |
| 有官职但无名字 | 取"姓+官职" | 翟买办 |
| 仅称谓/亲属代称 | TITLE_ONLY，canonical 取最通用形式 | 王冕母（别名"母亲"） |
| 历史/提及型人物 | 仍标为实体（PERSON），note 注明 | 方国珍、吴王(史实朱元璋) |

### 2.2 别名（aliases）

同指代的不同表面形式（含称谓、绰号、官职称呼、代称）。必须能落到原文。
例：王冕 → `["王相公", "王大叔", "王老大"]`；时仁 → `["时知县", "知县"]`。

### 2.3 类型与 nameType

- `type`: PERSON / LOCATION / ORGANIZATION / CONCEPT（对齐 EntityType）。
- `nameType`: NAMED（有名有姓或可唯一识别的称呼）/ TITLE_ONLY（仅泛称/职位/亲属代称，无名字）。TITLE_ONLY 例：王冕母、老太太。

### 2.4 锚点

- `firstAppearancePara`: 首次出现的段落序号（本回内从 1 数，跳过回目/字数行）。
- `activeChapters`: 实际出场的回目（跨章消歧用；单章标注时填当前回）。

## 3. 关系（relations）

- `typeCode`: 必须来自 relationship_types 全局 10 类：**父子 / 母子 / 兄弟 / 夫妻 / 师生 / 同年 / 同僚 / 主仆 / 朋友 / 仇敌**（书型专属码后续补充）。
- 方向：`source → target`（母子：source=母亲，target=子；师生：source=学生，target=师）。
- `evidence`: 直接引用原文一句，必须能定位到两人关系。
- 不在 10 类内的明确关系（如"干亲/干爷"）：**不标 relation**，可在 entity.note 记录。

## 4. 传记事实（bioFacts）

- `category`: 对齐 EventCategory —— BIRTH / EXAM / CAREER / TRAVEL / SOCIAL / DEATH / EVENT。
- `subjectCanonical`: 事实主语（必须存在于 entities）。
- `summary`: 一句话概述（不含模型推断，只写原文可证的事实）。
- `evidence`: 原文引用。

## 5. 判定边界（判据）

- **只标原文可证的事实**：没有直接原文支撑的判断（"王冕性格高傲"这类）不标为事实。
- **泛称不标为独立实体**：通行的"母亲/老爷/相公"若不能唯一指代，标为实体的别名而非新实体；能唯一指代（如本书的"母亲"=王冕母）才作 TITLE_ONLY 实体。
- **提及型历史人物照标**：方国珍/张士诚/陈友谅这类一笔带过的人物是实体，note 注明"提及"。
- **同场共现 ≠ 关系**：仅同段出现不构成 relation，必须有明确关系表述。

## 6. 冷门书对照

- 选《歧路灯》（备选《镜花缘》）第 1-2 回，同样的规范。
- 作用：检测模型是否依赖预训练记忆（儒林外史是教材内容）。

## 7. 质量流程

1. 标注首章（第 1 回）作校准样本，2 人互检一次统一口径。
2. 每章标注后跑 `schema.ts` 校验（zod + 悬空引用检查）。
3. 抽样回查：跨段 goldset 标注完成后，抽 1 章复标对比一致性。
