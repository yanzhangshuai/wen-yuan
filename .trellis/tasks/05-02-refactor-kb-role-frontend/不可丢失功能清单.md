# 05-02-refactor-kb-role-frontend 不可丢失功能清单

## 知识库域（/admin/knowledge-base/*）

- alias-packs
  - 别名包+条目+版本三级结构，包与条目分离、批量审核流
  - 条目版本历史与 diff 对比
  - 批量启用/停用/删除
- surnames/title-filters/ner-rules/prompt-extraction-rules
  - AI 生成（带参数、异步、生成后可编辑）
  - 批量操作（启用/停用/删除/清空选择）
  - 导入（文件上传、格式校验、导入预览）
- relationship-types
  - 关系类型 Sheet 编辑的所有字段、批量操作
- prompt-templates
  - 模板多版本管理、diff 对比
- name-patterns
  - 规则测试器（输入样例、实时校验、结果预览）
- change-logs
  - 只读、详情弹窗
- 全局
  - 列表筛选（前端/后端）、搜索、分页（如后端支持）
  - 错误提示（toast/顶部红条）、loading/空态
  - 权限校验（ADMIN）、URL 直链、未保存离开提示

## 角色资料域（/admin/role-workbench/*）

- 角色基础信息 Tab
  - 角色列表（搜索、过滤、排序、可折叠）
  - 角色详情四分区（基础/关系/传记/别名）
  - 角色编辑表单所有字段、校验、保存
  - 删除角色二次确认与级联影响预览
- 关系/传记/别名 Tab
  - 新增/编辑/删除，所有字段、批量操作
- 章节事迹 Tab
  - 章节列表、章节内角色事迹列表
  - 新增/编辑事件所有字段
- 合并建议 Tab
  - AI 合并建议列表、接受/拒绝/暂缓、合并工具字段对齐
  - 手动新建实体
- 别名映射 Tab
  - Table 展示别名→角色映射，逐行确认/驳回
- 自检报告 Tab
  - 报告卡片列表，逐条审阅
- 全局
  - 来源筛选（全部/AI/手动）、Tab 切换徽标（待办计数）
  - 权限校验、URL 直链、未保存离开提示

如有遗漏请补充，后续抽象/迁移时每项都需 checklist 覆盖。
